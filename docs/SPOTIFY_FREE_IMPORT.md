# Импорт библиотеки Spotify без Web API (бесплатно)

## Зачем

Подключение через официальный Spotify Web API (кнопка **Connect**) требует, чтобы
пользователь создал своё приложение в Spotify Developer Dashboard. С
[обновления Spotify от февраля 2026](https://developer.spotify.com) использование
Development Mode требует **активной подписки Premium** у владельца приложения —
бесплатный аккаунт через Web API подключить больше нельзя.

Для бесплатных аккаунтов работает путь **мимо API**: импорт официального экспорта
данных или CSV-файла стороннего экспортёра. Кнопка — **«Импорт файла»** на странице
Spotify; подключение аккаунта для неё не нужно.

## Вариант A — официальный экспорт «Download your data» (рекомендуется)

1. Зайдите на [spotify.com](https://www.spotify.com) → **Профиль → Аккаунт →
   Настройки конфиденциальности** (Account → Privacy settings).
2. Внизу страницы — **«Скачать ваши данные»** (Download your data). Подтвердите
   запрос по ссылке из письма.
3. Через несколько дней (обычно 1–5) Spotify пришлёт письмо со ссылкой на ZIP-архив.
4. На странице Spotify в плеере нажмите **«Импорт файла»** и выберите этот ZIP.
   Распаковывать не нужно.

Из архива плеер читает:

| Файл | Что берёт |
|---|---|
| `YourLibrary.json` | лайкнутые треки (аналог Liked Songs) |
| `Playlist*.json` | треки плейлистов (эпизоды подкастов и локальные файлы пропускаются) |

Если `YourLibrary.json` в архиве нет, импортируются треки плейлистов. Дубликаты
убираются по Spotify ID.

## Вариант B — CSV стороннего экспортёра

Подойдёт любой CSV с колонками названия/исполнителя: **Exportify** (открытие
плейлиста «Liked Songs» → Export CSV), **TuneMyMusic**, **Soundiiz** и т.п.
Колонки распознаются по именам (`Spotify ID`, `Track Name`, `Artist Name(s)`,
`Album Name`, `Duration (ms)`, `Artwork URL`, `Added At`); строки без ID получают
стабильный суррогатный ID по названию/исполнителю.

## Что происходит после импорта

Треки пишутся в ту же локальную таблицу `spotify_tracks`, которую использует
Web API-синк: карточки, матчинг с локальной библиотекой и воспроизведение через
локальные матчи работают одинаково. «Последняя синхронизация» обновляется.

## Ограничения

- JSON-экспорт Spotify не содержит обложек и длительности — карточки показывают
  заглушку вместо обложки. CSV с колонкой `Duration (ms)` / `Artwork URL`
  (например, Exportify) переносит и длительность, и обложки.
- Импорт — снимок на момент выгрузки: чтобы обновить библиотеку, запросите
  экспорт заново и импортируйте файл ещё раз (дубликаты не появятся).
- Кнопка Connect и Web API-синк остаются как есть — для аккаунтов с Premium.
